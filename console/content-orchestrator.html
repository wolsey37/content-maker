모델 입력칸을 클릭하면 추천 목록에서 고를 수 있습니다. 최신 목록은 [🔄 모델 최신화]로 갱신하고, 연결 상태는 상단 상태 배지로 확인합니다.
도움말 · 보안 안내
사전 준비 — 브리지 실행
  • 이 콘솔은 LLM을 직접 호출하지 않고, 로컬에 설치된 LLM CLI(claude / codex / agy)를 브리지 서버가 터미널에서 실행해 결과를 받아옵니다. (agy = Google Antigravity 에이전트 · Gemini 모델)
  • 터미널에서 console/ 폴더의 브리지를 실행: node bridge.mjs
  • 브리지가 출력한 주소(http://127.0.0.1:8787)를 브라우저로 열면 이 콘솔이 뜹니다.
  • 사용할 CLI가 설치·로그인되어 있어야 합니다. 상단 연결 상태 배지로 점검하세요.
  • LLM·모델은 상단 [⚙ 설정]에서 선택합니다. codex·claude는 모델 입력칸을 클릭해 목록에서 고르고([🔄 모델 최신화]로 목록 갱신), agy는 자체 기본 모델을 사용합니다.
보안 주의
API 키는 어디에도 저장하지 않습니다. 각 CLI 자체 로그인을 사용합니다.
· 브리지는 127.0.0.1 에만 바인딩되어 외부에 노출되지 않습니다. 콘솔을 쓸 때만 켜두고 끝나면 종료(Ctrl+C)하세요.
· CLI는 임시 폴더에서 실행되어 이 저장소 파일을 읽지 않습니다.
범위
기본은 이미지·영상 제작용 스크립트를 생성합니다. 카드뉴스·피드·스토리는 codex·agy 로 실제 이미지를, 릴스는 영상 엔진(Higgsfield)을 codex·claude CLI→MCP 로 호출해 실제 영상까지 만들어 작업폴더 output/ 에 저장합니다.
