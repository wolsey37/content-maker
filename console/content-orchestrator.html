콘텐츠 제작
로컬 LLM CLI 실행 · 제작 스크립트 + 릴스는 영상 엔진(Higgsfield)으로 실제 영상까지

⚠️ 아직 준비가 안 됐어요

콘텐츠를 만들려면 PC에서 작은 연결 프로그램을 먼저 켜야 합니다. 터미널에 아래 한 줄을 붙여넣고 실행하세요.

cd console && node bridge.mjs
  1. 위 명령을 터미널에서 실행합니다.
  2. 실행되면 아래 [다시 확인]을 누르거나 페이지를 새로고침하세요.
콘텐츠 종류 선택
🔒 진행 중에는 콘텐츠 종류를 바꿀 수 없어요. (주제·분석 기준은 수정 가능) 바꾸려면 [🗑 새로 시작]을 누르세요.

어떤 콘텐츠를 만들까요?

주제만 입력하면 기획 → 대본 → 이미지·영상 프롬프트까지 만들어 드려요. (한 번에 끝내려면 ⏩ 전체 자동)

🔎 웹 자료 가져오기 선택
LLM이 사이트를 검색·요약해 참조 자료에 추가합니다. 미추가 시 웹 전체 검색 · 쉼표·공백으로 여러 개 추가 가능
📑 참조 자료 선택
웹 조사 결과가 쌓여 1단계에 반영됩니다. 주제 칸과 별개 · 로그인 사이트는 직접 붙여넣기
📋 분석 기준 선택
규제·점수 기준을 넣으면 더 정확합니다.
⚙️ 설정
모델 입력칸을 클릭하면 추천 목록에서 고를 수 있습니다. 최신 목록은 [🔄 모델 최신화]로 갱신하고, 연결 상태는 상단 상태 배지로 확인합니다.
