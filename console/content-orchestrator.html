⚠️ 아직 준비가 안 됐어요

콘텐츠를 만들려면 PC에서 작은 연결 프로그램을 먼저 켜야 합니다. 터미널에 아래 한 줄을 붙여넣고 실행하세요.

cd console && node bridge.mjs
  1. 위 명령을 터미널에서 실행합니다.
  2. 실행되면 아래 [다시 확인]을 누르거나 페이지를 새로고침하세요.

어떤 콘텐츠를 만들까요?

주제만 입력하면 기획 → 대본 → 이미지·영상 프롬프트까지 한 번에 만들어 드려요.

플랫폼
분석 기준 (선택) — 규제·점수 기준을 넣으면 더 정확해요
도움말 · 보안 안내 (처음이면 펼쳐 읽어주세요)
사전 준비 — 브리지 실행
  • 이 콘솔은 LLM을 직접 호출하지 않고, 로컬에 설치된 LLM CLI(codex / claude / gemini)를 브리지 서버가 터미널에서 실행해 결과를 받아옵니다.
  • 터미널에서 console/ 폴더의 브리지를 실행: node bridge.mjs
  • 브리지가 출력한 주소(http://127.0.0.1:8787)를 브라우저로 열면 이 콘솔이 뜹니다(같은 origin이라 CORS 문제 없음).
  • 사용할 CLI가 설치·로그인되어 있어야 합니다. 상단 연결 상태 pill로 점검하세요.
사용법
  • 설정에서 LLM(CLI) 선택 → 기본 모델명 → 전역 입력(주제·룰팩·플랫폼)을 채웁니다.
  • 각 단계 실행, 또는 상단 전체 순차 실행으로 1→6단계를 자동 진행합니다(오류 시 중단).
  • 이전 단계 결과가 다음 단계 프롬프트에 자동 반영됩니다(carry-forward). 결과는 편집 가능.
  • 결과의 복사 버튼으로 스크립트를 그대로 이미지/영상 툴에 붙여넣으세요.
  • 입력·템플릿·결과는 localStorage에 저장됩니다. JSON / Markdown 내보내기로 백업하세요.
보안 주의
API 키는 어디에도 저장하지 않습니다. 각 CLI 자체 로그인을 사용합니다.
· 브리지는 127.0.0.1 에만 바인딩되어 외부에 노출되지 않습니다. 콘솔을 쓸 때만 켜두고 끝나면 종료(Ctrl+C)하세요.
· CLI는 임시 폴더에서 실행되어 이 저장소 파일을 읽지 않습니다.
범위
본 콘솔은 이미지·영상 제작용 "스크립트"까지만 생성합니다. 실제 영상 생성(Hailuo/Kling/Premiere 등)은 별도 툴에서 진행합니다.
⚙️ 고급 설정 (LLM·모델·내보내기)
모델명은 직접 입력하거나 [모델 ▾]에서 고를 수 있습니다. 연결 상태는 상단 상태 배지를 클릭해 확인합니다. 주제·플랫폼·분석 기준은 위쪽 입력창에서 채웁니다.
입력·템플릿·결과는 자동으로 localStorage에 저장됩니다. (API 키는 저장하지 않습니다 — CLI 자체 로그인 사용)

단일 HTML + 로컬 브리지(Node, 의존성 0) · LLM은 로컬 CLI 실행 · 본 콘솔은 스크립트까지만 생성하며 실제 영상 생성은 별도 툴에서 진행합니다.
